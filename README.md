# Users Table

Тестовий проєкт на Nuxt 3 — таблиця користувачів з фільтрацією, сортуванням та пагінацією.

## Функціонал

- Пошук по імені та email з debounce
- Фільтрація по ролі (admin, manager, user)
- Сортування по колонках
- Пагінація з вибором кількості елементів на сторінці
- Збереження стану фільтрів у query params (URL)
- Три теми: Light, Dark, Matrix

## Стек

- Nuxt 3
- Vue 3 (Composition API)
- TypeScript

## Запуск

```bash
npm install
npm run dev
```

Відкрити: `http://localhost:3000`
